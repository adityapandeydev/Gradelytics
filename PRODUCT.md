# Gradelytics

## Platform

web

## Users and purpose

College students tracking academic records, calculating GPA, comparing grade improvements, and planning curriculum progress.

## Confirmed scope

The frontend preview uses clearly labeled fictional data and browser-local storage. React, TypeScript, Bun, Vite, and Tailwind CSS v4 through the Vite plugin. Support 4-, 5-, 9-, and 10-point grading profiles, decimal points, custom grade mappings, F and pass-only P, and zero-credit requirements. Exam assessment formulas are deferred. Commit and push when explicitly requested.

The user approved the palette, typography, and layout and requested quick center-expanding button fills, press feedback, an animated theme toggle, page transitions, and chart/progress entrances. Preserve reduced-motion access.

Backend work is now authorized. The first slice is a stateless Go calculation API, separate from the preview. PostgreSQL persistence, accounts, ownership checks, and frontend integration remain subsequent stages; do not imply they already exist.

## Brand commitments

Primary colors #DDE3E8 and #3A0F34 with reversed emphasis in dark mode. Use UI UX Pro Max, Emil Kowalski, and Impeccable; exclude Taste.

## Preview assumptions

Use a fictional computer science curriculum and six completed semesters. Repeat scenarios use grade replacement for illustration, not a verified university policy. User edits are saved only in this browser. Curriculum rules and dates are illustrative.
